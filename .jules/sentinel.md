## 2026-06-29 - Prevent FormData DoS and Type Crashes\n**Vulnerability:** Unchecked casting of `formData.get()` to string allows `File` objects to crash server actions, and lacks length limits exposing Prisma errors or DoS vectors.\n**Learning:** Next.js server actions receive `FormData` which can contain strings or files. Trusting it's a string via `as string` bypasses TypeScript's safety, leading to runtime crashes.\n**Prevention:** Always use a helper like `getValidString` that checks `typeof === 'string'` and enforces maximum length before using FormData inputs.
